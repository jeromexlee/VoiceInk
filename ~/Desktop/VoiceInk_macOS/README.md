# VoiceInk - macOS 语音转文字应用

这是一个强大的本地语音转文字应用，基于 whisper.cpp 构建，支持 macOS 14.0+。

## 📦 安装说明

### 方法一：直接运行（推荐）
1. 解压下载的文件
2. 将 `VoiceInk.app` 拖拽到 `/Applications` 文件夹
3. 右键点击应用，选择"打开"
4. 在弹出的安全警告中点击"打开"

### 方法二：通过终端授权
如果应用无法运行，请在终端中运行：
```bash
sudo xattr -rd com.apple.quarantine /Applications/VoiceInk.app
```

## 🎯 首次使用

1. **下载模型**：首次启动会引导你下载 AI 模型
2. **权限设置**：授予必要的麦克风和辅助功能权限
3. **语言选择**：在 AI Models 标签页选择转录语言

## ✨ 主要功能

- 🎤 **实时录音转录**：支持多种录音模式（push-to-talk、toggle等）
- 📁 **音频文件转录**：支持导入音频文件进行转录
- 🌍 **多语言支持**：支持中文、英文等多种语言
- ⚙️ **参数调节**：可调节 Context Window、Entropy Threshold 等高级参数
- 🕐 **时间戳显示**：可选择显示转录文本的时间戳
- 📊 **进度显示**：实时显示转录进度
- 🎨 **现代界面**：美观易用的 macOS 原生界面
- 🚀 **实时转录**：转录过程中实时显示已完成的segments
- 🆓 **完全免费**：所有功能均可免费使用，无试用期限制

## ⚠️ 系统要求

- macOS 14.0 或更高版本
- Apple Silicon (M1/M2/M3) 或 Intel Mac
- 至少 4GB 可用存储空间（用于模型文件）

## 🔧 故障排除

### 应用无法启动
- 确认系统版本为 macOS 14.0+
- 使用上述终端命令移除隔离属性
- 检查应用是否在 `/Applications` 目录

### 无法录音
- 前往系统设置 > 隐私与安全性 > 麦克风，授予权限

### 转录效果不佳
- 在 AI Models 标签页调整参数
- 尝试不同的模型
- 确保音频质量良好

## 📝 使用技巧

1. **Context Window**: 设为 0 可提高准确性，但会稍慢一些
2. **Entropy Threshold**: 值越低越敏感，推荐 2.4
3. **时间戳功能**: 适合需要精确定位的场景
4. **多语言**: 选择 "auto" 可自动检测语言
5. **实时转录**: 在转录长音频时可实时查看已完成的部分

## 🎮 快捷键

- **Push-to-Talk**: 按住快捷键录音，松开停止
- **Toggle 录音**: 按一次开始，再按一次停止
- **迷你录音器**: 显示小窗口录音界面
